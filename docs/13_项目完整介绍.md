## 一、这是什么

**8 类课堂行为检测系统**：用 YOLOv11 识别教室画面里每个学生在做什么，并给出统计、预警和报表。

| 8 个类别 | | | |
|---|---|---|---|
| 抬头听讲 | 阅读看书 | 书写记笔记 | 举手发言 |
| 站立回答 | 小组讨论 | 趴桌睡觉 ⚠️ | 玩手机 ⚠️ |

后两类是异常行为，会触发预警。

系统有两个端，共用同一套检测逻辑：

- **桌面端**（PyQt5）：图片 / 视频 / 摄像头，带播放控制、截图、录制
- **网页端**（Streamlit）：浏览器访问，图片 / 视频 / 摄像头拍照

两端都带：目标跟踪（每个学生一个稳定 ID）、行为时长统计、抬头率/参与度、异常预警列表、CSV/Excel/Markdown 报表导出。

## 四、怎么跑起来

### 第 1 步：装环境（约 20 分钟）

先确认自己有没有 **NVIDIA 显卡**，命令不一样：

```bash
conda create -n classroom python=3.11 -y
conda activate classroom
cd /d D:\2026srp

# 有 NVIDIA 显卡（要训练）：约 2.5 GB
pip install torch==2.7.1 torchvision==0.22.1 --index-url https://download.pytorch.org/whl/cu128

# 没有显卡（只运行/改代码）：约 200 MB
#   pip install torch torchvision

pip install -r requirements.lock.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
python scripts/check_env.py
```

`check_env.py` 会逐项检查并给出结论。没显卡会显示 ⚠️ 而不是 ❌，属正常。

### 第 2 步：放数据

- 只需要跑通 → 解压 455 MB 子集到 `D:\2026srp`
- 要正式训练 → 解压 5.3 GB 完整数据到 `D:\2026srp\data`

### 第 3 步：跑

```bash
python scripts/smoke_test.py            # 端到端自检
python scripts/train.py --smoke         # 训练链路冒烟
python app\desktop_app.py               # 桌面端
python -m streamlit run app\web_app.py  # 网页端
```

也可以直接双击 `run_app.bat` / `run_web.bat`（会自动找 python）。

**没显卡也能运行识别程序**：程序检测到没有 CUDA 会自动降级到 CPU。

| | CPU | GPU (RTX 5070) |
|---|---|---|
| 单张图片 | 170 ms | 46 ms |
| 视频/摄像头 | 约 6 FPS | 22 FPS |
| 训练 | ❌ | ✅ |

## 五、怎么分工

| 角色 | 人数 | 硬件要求 | 干什么 |
|---|---|---|---|
| **训练组** | 1~2 | NVIDIA 8 GB+ | 跑训练、调参、出指标报告 |
| **数据组** | 2 | 无 | 自采本校数据、补弱类、标注质检 |
| **系统组** | 2 | 无 | 阈值、预警、跟踪、界面、报表 |
| **文档实验组** | 1 | 无 | 消融方案、训练曲线、报告章节 |

**关键认知**：改代码不需要 GPU，**跑推理也不需要**（CPU 就能跑），只有**训练**需要。
