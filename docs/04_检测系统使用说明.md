# 课堂行为检测系统使用说明

系统包含两个可视化入口，共用 `src/` 下的检测与分析模块：

| 入口 | 文件 | 适用场景 |
| --- | --- | --- |
| 桌面端（PyQt5） | `app/desktop_app.py` | 教室现场演示、摄像头实时检测（推荐） |
| 网页端（Streamlit） | `app/web_app.py` | 浏览器访问、快速上传图片/视频演示 |

## 一、启动

```powershell
# 桌面端（双击 run_app.bat 亦可）
app\desktop_app.py

# 指定权重启动
app\desktop_app.py --weights runs\train\classroom_yolo11s\weights\best.pt

# 网页端（双击 run_web.bat 亦可），浏览器打开 http://localhost:8501
-m streamlit run app\web_app.py
```

首次启动会加载模型（几秒）；如果 `configs/app.yaml` 里的权重不存在，会自动回退到 `yolo11n.pt`
（COCO 预训练模型，只认「人」，用于先跑通界面，**不是课堂行为模型**）。

## 二、桌面端界面说明

窗口**最顶部是一条类别图例**：8 个色块 + 中文类别名，颜色与画面里的框、标签底牌一一对应，
不用再靠记忆猜"这个框是哪种行为"（鼠标悬停色块可看到该类别的定义）。

```
┌──────────────────────────────────────────────────────────────────────┐
│ 类别图例  ■抬头听讲 ■阅读看书 ■书写记笔记 ■举手发言 ■站立回答 …        │
├──────────────┬──────────────────────────────┬──────────────────────┤
│  功能按钮     │                              │  实时行为统计表       │
│  · 本地图片   │        视频 / 图片显示区       │  · 各行为人数         │
│  · 本地视频   │   （画框 + 中文类别 + 置信度）  │  · 人数/抬头率 KPI    │
│  · 摄像头     │                              ├──────────────────────┤
│  · 停止       │                              │  可视化               │
│  · 导出报表   │                              │  · 行为时长柱状图      │
├──────────────┤                              │  · 抬头率环形图        │
│  参数         │                              │                      │
│  · 跟踪开关   │                              │                      │
│  · 置信度     ├──────────────────────────────┤                      │
│  · 推理尺寸   │  状态栏：模型 / FPS / 目标数   │                      │
├──────────────┤                              │                      │
│  异常预警列表 │                              │                      │
└──────────────┴──────────────────────────────┴──────────────────────┘
```

标签文字颜色会按底牌亮度自动切成黑/白：黄、青绿这类亮色（如「站立回答」「小组讨论」）用黑字，
深色（如「趴桌睡觉」「玩手机」）用白字，并统一描一圈黑边，投到浅色墙面的画面上也不会糊。

### 操作步骤

1. **本地图片检测**：点击按钮选图 → 立即显示检测结果 → 结果图自动保存到 `reports/detect_*.jpg`；
2. **本地视频检测**：选视频后逐帧检测，右侧统计实时刷新；播放结束自动停止；
3. **摄像头实时检测**：打开本机摄像头（默认 0 号，可在 `configs/app.yaml` 改 index）；
   * 摄像头画面**实时逐帧检测**（等于"摄像头视频识别"）；
   * 点 **`抓拍当前画面（存为图片）`** 可把当前帧存成图片（等于"摄像头拍照识别"），文件在 `reports/detect_*.jpg`；
4. **保存检测结果视频**：勾选 `保存检测结果视频（mp4）` 后，视频/摄像头模式会自动把带框画面录成
   `reports/videos/检测结果_<时间>.mp4`，可直接放进结题报告或答辩演示；
5. **参数调整**：
   * *置信度阈值*：漏检多就调低（0.25），误检多就调高（0.5）；
   * *推理尺寸*：人数多、后排小目标多 → 调到 768/960（速度变慢）；追求流畅 → 512；
   * *启用目标跟踪*：开启后每个学生有稳定编号（`#1`、`#2`…），才能统计「行为时长/抬头率」；关闭则只做逐帧人数统计；
6. **导出报表**：一键生成 Excel / CSV / Markdown / 图表（见下表）。

## 三、导出产物（保存在 `reports/`）

| 文件 | 内容 |
| --- | --- |
| `课堂行为报表_<时间>.xlsx` | 总览 / 行为分布 / 学生画像 / 逐帧明细 / 预警记录，5 个 Sheet |
| `timeline_<时间>.csv` | 逐帧统计明细（人数、抬头率、各行为人数），可直接画曲线 |
| `报告_<时间>.md` | 中文文字报告（总体指标、行为分布、学生画像、预警清单） |
| `behavior_distribution.png` | 行为时长柱状图 |
| `attention_rate.png` | 抬头/参与率环形图 |
| `trend_<时间>.png` | 抬头率与人数随时间变化曲线 |
| `alerts.jsonl` | 异常预警流水（每行一条 JSON，便于二次分析） |
| `dataset_stats.md` / `dataset_check.md` / `label_check.md` | 数据集相关报告（由脚本生成） |
| `val_report_test.md` | 模型评估报告（由 `scripts/val.py` 生成） |

## 四、指标口径说明（写报告时可直接引用）

| 指标 | 计算方式 |
| --- | --- |
| 抬头率 | 最近统计窗口内「抬头听讲/阅读/书写/举手/站立」人数 ÷ 画面总人数，按人数加权 |
| 参与度 | 与抬头率同源，可按需把「小组讨论」计入参与行为（改 `configs/app.yaml` 的 `attention_classes`） |
| 行为时长 | 同一跟踪目标在某行为上的持续秒数累加（相邻帧时间差求和，单帧间隔截断为 ≤1 秒，防止卡顿虚高） |
| 逐学生画像 | 每个跟踪 ID 的各行为时长、主要行为、异常时长 |
| 异常预警 | 规则见 `configs/classes.yaml` 的 `anomaly_rules`：趴桌睡觉 ≥ 8 秒、玩手机 ≥ 5 秒触发，同一学生同一行为 10 秒冷却 |

## 五、参数配置（`configs/app.yaml`）

```yaml
model:
  weights: runs/train/classroom_yolo11s/weights/best.pt
  device: 0          # 0=GPU；cpu=CPU
  imgsz: 640
  conf: 0.35
  iou: 0.45
tracking:
  enable: true
  tracker: bytetrack.yaml
  max_age: 30
analysis:
  attention_classes: [抬头听讲, 阅读看书, 书写记笔记, 举手发言, 站立回答]
  anomaly_classes: [趴桌睡觉, 玩手机]
  sleeping_seconds: 8
  phone_seconds: 5
camera:
  index: 0
```

预警阈值在 `configs/classes.yaml` 的 `anomaly_rules` 中调整（例如把玩手机改为 10 秒触发，避免误报）。

## 六、网页端使用

`streamlit run app/web_app.py` 后浏览器打开四个标签页（标题下方同样有一排**类别图例**色块）：

* **图片检测**：上传图片 → 显示检测结果与目标清单 → 可保存结果图；
* **视频检测**：上传视频 + 设置抽帧间隔 → 处理完成后在线播放结果视频，并给出汇总报表；
* **摄像头检测**：浏览器摄像头拍照检测（连续实时检测请用桌面端）；
* **数据看板**：直接展示数据集统计报告与模型评估报告，方便汇报时展示。

## 七、常见问题

| 问题 | 解决 |
| --- | --- |
| 界面卡住不动 | 视频/摄像头模式下调大抽帧间隔或降低推理尺寸；确认显卡未被其它程序占满 |
| 摄像头打不开 | 关闭占用摄像头的程序（QQ/微信/会议软件），或改 `camera.index` 为 1 |
| 检测框全是「人」 | 当前用的是回退权重 `yolo11n.pt`，需在 `configs/app.yaml` 指向训练好的课堂行为权重 |
| 中文类别显示成方块 | 系统缺少中文字体，检查 `C:\Windows\Fonts\msyh.ttc` 是否存在 |
| 导出 Excel 失败 | 缺 openpyxl：`pip install openpyxl` |
| 跟踪 ID 频繁跳变 | 遮挡严重场景可换 `botsort.yaml`；或把置信度调低、推理尺寸调高 |
| 想连续实时检测 | 用桌面端；网页端受浏览器限制只能拍照 |
