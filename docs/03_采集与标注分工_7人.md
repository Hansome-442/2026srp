# 数据采集与标注分工方案（7 人协作）

> 对应预期成果 1 中的「7 位同学可以互相搭档」，以及进度安排中 2026 年 7—12 月的数据采集标注任务。

## 一、总体思路

7 人**互为拍摄对象**：一部分人扮演学生、一部分人拍摄/抽帧，轮换进行，这样能低成本产出
多学段、多场景、多人数的课堂视频；再把视频抽帧成图片，分头标注，交叉质检。

```
拍摄/收集视频  →  抽帧（collect_helper.py frames）  →  分工（collect_helper.py assign）
        →  标注（labelImg）  →  校验（collect_helper.py check）  →  合并（collect_helper.py merge）
        →  转换划分（prepare_dataset.py）  →  训练（train.py）
```

## 二、角色分工（每 2 周轮换一次，避免疲劳与偏差）

| 角色 | 人数 | 职责 | 产出 |
| --- | --- | --- | --- |
| 数据采集组 | 2 | 拍摄/收集课堂视频（多场景、多学段），抽帧去重 | `data/to_label/<场景>_<学段>/*.jpg` |
| 标注 A 组 | 2 | 标注普通行为（听讲/阅读/书写/讨论/站立） | VOC XML 或 YOLO txt |
| 标注 B 组 | 2 | 标注难点类（举手/趴桌/**玩手机**） | 同上，玩手机类必须由本组专门采集 |
| 质检 + 训练组 | 1 | 抽检标注、跑 `check`、运行数据转换与训练、维护统计报告 | `reports/*`、训练权重 |

> 轮换规则：第 3 周起，采集组 ↔ 标注 A 组互换，标注 B 组 ↔ 质检组互换，保证每个人都熟悉全流程。

## 三、时间安排（2026.07—12）

| 阶段 | 时间 | 任务 | 里程碑 |
| --- | --- | --- | --- |
| 准备期 | 7 月第 1—2 周 | 确定 8 类定义、搭建采集环境、试拍 200 张 | 标注规范定稿，抽帧脚本跑通 |
| 采集期 1 | 7 月第 3 周—8 月 | 拍摄/收集 4 个场景 × 4 个学段视频，抽帧 3000 张 | 图片 ≥ 3000，七类齐全 |
| 标注期 1 | 8 月—9 月 | 完成 3000 张标注 + 交叉质检 | 校验零错误，统计报告出炉 |
| 采集期 2 | 9 月—10 月 | 专门补采稀有类：举手发言、**玩手机**、趴桌睡觉 | 每类实例 ≥ 1200（玩手机 ≥ 1500） |
| 标注期 2 | 10 月—11 月 | 补标 + 全量质检 | **总样本 ≥ 5000** |
| 训练部署 | 11 月—12 月 | `prepare_dataset` → `train` → `val` → 接入系统 | 模型可用，系统演示通过 |

每周固定一次 30 分钟组会：过一遍 `reports/dataset_stats.md`（样本量、类别分布、未识别标签）和待办清单。

## 四、具体操作步骤

### 1) 抽帧

```powershell
& E:\anaconda3\envs\pytorch\python.exe scripts\collect_helper.py frames `
  --video "D:\课堂视频\2026-07" --out data\to_label --stride 30 --scene 教室后排 --stage 大学
```

参数说明：`--stride 30` 表示每 30 帧取一张（25fps 视频约 1.2 秒一张）；
脚本会自动丢弃模糊帧（拉普拉斯方差 < 60）和与上一张几乎相同的帧（差异 < 2），避免重复标注。

### 2) 分工（7 人）

```powershell
& E:\anaconda3\envs\pytorch\python.exe scripts\collect_helper.py assign --src data\to_label --out data\assignments --members 7
```

生成 7 份 `成员N_任务清单.csv` 和 `分工表.md`，每人按清单标注自己那批图片。

### 3) 标注（labelImg）

```powershell
pip install labelImg      # 若未安装
labelImg
```

操作要点：

1. 打开图片目录 → `Change Save Dir` 设为同目录（或 `labels/`）；
2. 左侧 `PascalVOC`（推荐）或 `YOLO` 格式切换；
3. `Create RectBox` 画框后，**类别名必须用中文类别名**：抬头听讲 / 阅读看书 / 书写记笔记 / 举手发言 / 站立回答 / 小组讨论 / 趴桌睡觉 / 玩手机；
4. 快捷键：`W` 画框、`D` 下一张、`A` 上一张、`Ctrl+S` 保存；
5. 建议在 `labelImg/data/predefined_classes.txt` 中预先写入这 8 个中文类别名，避免手打错别字。

### 4) 校验

```powershell
& E:\anaconda3\envs\pytorch\python.exe scripts\collect_helper.py check --labels data\to_label\labels
```

输出 `reports/label_check.md`：类别分布 + 问题明细（类别 id 越界、坐标越界、框过小、空文件）。
**问题清零后才能合并。**

### 5) 合并 7 人成果

```powershell
& E:\anaconda3\envs\pytorch\python.exe scripts\collect_helper.py merge --src data\to_label\labels_m1 data\to_label\labels_m2 ... --out data\raw\self_collected
& E:\anaconda3\envs\pytorch\python.exe scripts\prepare_dataset.py --voc-dir data\raw\classroom_voc --yolo-dir data\raw\self_collected --oversample-min 300
```

## 五、质检规则（质检组必读）

1. **抽检比例**：每人标注量的 10%，且覆盖全部 8 类；稀有类（举手、玩手机）100% 复核；
2. **一致性判定**：两人对同一张图的类别判断一致才算通过；不一致的以规范第 4.2 节的优先级为准；
3. **错标率 > 5%** → 该成员当批全部返工；
4. **常见错误清单**（重点检查）：
   * 框太大（框到邻座）或太小（只框头）；
   * 阅读 ↔ 书写 混淆；
   * 学生低头看手机被标成「阅读看书」；
   * 趴桌但头抬起被标成「趴桌睡觉」；
   * 一张图里同一个学生标了两个框；
   * 类别名用了简称（听讲/看书/写字），未按别名表规范书写。

## 七、数据合规提醒

* 拍摄需获得学校/教师许可，涉及真实学生的视频必须取得同意，公开数据请注明来源；
* 发布数据集时对人脸做模糊化处理或仅发布标注文件；
* 不要在数据集中保留学生姓名、学号等个人信息。
