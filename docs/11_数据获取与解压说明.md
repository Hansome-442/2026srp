# 数据获取与解压说明

> 网盘里有两个数据包，**大小和用途完全不同**，别下错。
> 最后更新：2026-11-17

---

## 一、两个数据包，怎么选

| 文件 | 大小 | 内容 | 谁需要 |
|---|---|---|---|
| `2026srp_subset_20261117.zip` | **455 MB** | 3,400 张，8 类均衡子集 | **所有人先下这个**，当天就能跑通 |
| `2026srp_dataset_20261117_part01.zip` | **5.3 GB** | 46,760 张完整数据集 | 要正式训练、复现指标的人 |

**建议顺序**：先下 455 MB 的子集，把环境、代码、训练链路全部跑通；确认没问题了，再挂一晚上下 5.3 GB。

> 子集只有 3,400 张，训出来的模型精度没有参考价值，**别拿它的指标写报告**。

---

## 二、为什么不能在网盘里「在线解压」

这是问得最多的问题，答案是：**不能，而且就算能也别这么干。**

### 原因 1：能力上不支持

百度网盘的「在线解压」是会员功能，而且对单文件大小有上限。5.3 GB 的 zip 对普通用户基本解不开。

### 原因 2（更关键）：解压出来是 9 万个小文件

完整数据集解压后是 **93,524 个文件**（4.6 万张图 + 4.6 万个标签）。如果在网盘里解压，这些文件会散在你的网盘里，然后你要一个个下载：

| 下载对象 | 实际体验 |
|---|---|
| **1 个** 5.3 GB 的 zip | 单条数据流，支持断点续传，几小时能下完 |
| **93,524 个**小文件 | 每个文件都要单独建立连接，速度可能掉到十分之一，还经常失败 |

**打包成大 zip 的唯一目的，就是避免这种「小文件地狱」。**

### 结论

| 在哪解压 | 行不行 |
|---|---|
| 网盘里在线解压 | ❌ 不支持，也不应该 |
| **下载到本地再解压** | ✅ 正确做法 |

## 三、完整流程（四步）

### 第 1 步：下载到本地

用**百度网盘客户端**（不要用网页版），把 zip 下载到本地。

- 一个大文件，支持断点续传，断了能接着下
- 建议睡前挂着，第二天早上收
- 目标目录注意留足空间：**zip 本身 5.3 GB + 解压后 5.3 GB = 至少 11 GB 空闲**

### 第 2 步：校验（建议做）

数据传了几 GB，损坏一两张图很常见，校验能提前发现。

把 `MD5SUMS.txt` 和 zip 放在同一个文件夹，然后：

```bash
# Windows 自带，不用装任何东西
certutil -hashfile 2026srp_dataset_20261117_part01.zip MD5
```

拿输出的值和 `MD5SUMS.txt` 里那行对比，一致才继续。

> 项目里也有脚本版本，能自动逐个核对：
> `python scripts\pack_dataset.py --verify .`

### 第 3 步：解压到正确的位置

**完整数据集解压到**：`D:\2026srp\data\`

**子集解压到**：`D:\2026srp\`（项目根目录）

用 7-Zip / WinRAR / Windows 自带的「全部解压缩」都行。

解压完必须是这个结构：

```
D:\2026srp\
├─ data\
│  ├─ dataset.yaml                      ← 完整数据集
│  ├─ processed\images\{train,val,test}
│  ├─ processed\labels\{train,val,test}
│  ├─ subset\images\{train,val,test}    ← 子集
│  └─ subset.yaml                       ← 子集
├─ app\
├─ src\
└─ scripts\
```

**最常见的错误**：解压出了 `data\processed\processed\images`，多套了一层。发现图片数是 0，先查这里。

### 第 4 步：确认

```bash
cd /d D:\2026srp
python scripts\check_env.py
```

看到这两行就对了：

```
✅ data/processed/images/train        34603 个文件     ← 完整数据集
✅ data/subset/images/train          2000 个文件       ← 子集
```

## 四、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 解压报「文件已损坏」 | 下载不完整 | 重新下载，下完先校验 MD5 |
| `check_env` 显示图片 0 张 | 解压层级错了 | 确认是 `data\processed\images`，不是 `data\processed\processed\images` |
| 解压到一半空间不足 | 需要 11 GB | 清理磁盘，或解压到 D 盘 |
| 下载速度只有 100 KB/s | 非会员限速 | 用客户端、睡前挂、领闲时下载卡；或先只用 455 MB 子集 |
| Windows 右键解压失败 | 自带解压对大 zip 不稳 | 装 7-Zip 或 WinRAR |

---

## 五、如果实在下不动 5.3 GB

**你其实可以先不开工等它。** 455 MB 的子集 + 34 MB 的交接包，足够把：

- 环境装好
- 界面跑起来
- 训练链路跑通（10 轮能跑完、loss 在降）

这些都不需要完整数据集。等分工确定了、知道自己要做什么，再让需要训练的人去下大包。

**真正需要全量数据的，通常只有 2~3 个人。**
