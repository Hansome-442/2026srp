# 数据集规范与 8 类课堂行为定义

> 对应预期成果 1：构建多场景、多学段课堂行为数据集，样本量 ≥ 5000，覆盖 8 类核心课堂行为。

## 一、8 类行为定义（唯一权威来源：`configs/classes.yaml`）

| id | 类别（中文标注名） | data.yaml 英文名 | 判定要点 | 属性 | 预估难度 |
| --- | --- | --- | --- | --- | --- |
| 0 | 抬头听讲 | listening | 面向前方/黑板，头部抬起，身体直立 | 正常 | 易 |
| 1 | 阅读看书 | reading | 低头看桌面书本/资料，视线落在桌面 | 正常 | 中（与书写易混） |
| 2 | 书写记笔记 | writing | 手握笔在纸面书写，手部有笔 | 正常 | 中（与阅读易混） |
| 3 | 举手发言 | hand_raising | 单臂或双臂上举且高于肩 | 积极 | 难（样本最少） |
| 4 | 站立回答 | standing | 起立站立、身高明显高于坐姿同学 | 积极 | 中 |
| 5 | 小组讨论 | discussing | 头部转向同桌、身体侧向，与同伴交流 | 正常 | 中（与听讲易混） |
| 6 | 趴桌睡觉 | sleeping | 头伏在桌面/手臂上，身体长时间不动 | 异常 | 中 |
| 7 | 玩手机 | using_phone | **自采新增类**：低头双手持手机、屏幕光明显、持机姿势 | 异常 | 难（样本需自建） |

标注时**必须使用中文类别名**（如「抬头听讲」）；标签里的其它写法（听讲、看书、写字、举手、睡觉、手机…）
已在 `configs/classes.yaml` 的 `aliases` 中配置别名，转换脚本会自动归一化；
遇到别名表未覆盖的写法，转换脚本会在 `reports/dataset_stats.md` 的「未识别标签」中列出，请补充 `aliases` 后重跑。

## 二、样本量规划（目标 ≥ 5000 张）

数据集规模不止看图片数，还要看**每类实例数**（一个框算一个实例），稀有类的实例数直接决定 mAP。

| 类别 | 目标图片数 | 目标实例数 | 说明 |
| --- | --- | --- | --- |
| 抬头听讲 | ≥ 2500 | ≥ 15000 | 课堂主行为，占比最大 |
| 阅读看书 | ≥ 1500 | ≥ 6000 | |
| 书写记笔记 | ≥ 1500 | ≥ 6000 | |
| 小组讨论 | ≥ 1200 | ≥ 4000 | |
| 站立回答 | ≥ 800 | ≥ 1500 | |
| 趴桌睡觉 | ≥ 600 | ≥ 1200 | 异常行为，需专门采集 |
| 举手发言 | ≥ 600 | ≥ 1200 | 稀有类，重点补采 |
| 玩手机（自采） | ≥ 700 | ≥ 1500 | 新增类，全部自采自标 |
| **合计** | **≥ 5000（去重后）** | ≥ 36000 | 一张图可含多类，故图片数小于各类之和 |

采集时用 `scripts/collect_helper.py check` 随时查看每类实例数是否达标。

## 三、多场景 / 多学段覆盖矩阵

| 学段 \ 场景 | 教室后排全景（固定摄像头） | 教室前侧（逆光/侧光） | 小组讨论区 | 讲台近景 |
| --- | --- | --- | --- | --- |
| 小学 | ≥ 300 | ≥ 200 | ≥ 150 | ≥ 100 |
| 初中 | ≥ 400 | ≥ 250 | ≥ 200 | ≥ 150 |
| 高中 | ≥ 500 | ≥ 300 | ≥ 250 | ≥ 150 |
| 大学 | ≥ 800 | ≥ 400 | ≥ 400 | ≥ 250 |

> 注意：**学段与行为强耦合**——大学课堂几乎不出现「举手发言」，小学课堂几乎不出现「玩手机」。
> 因此混合训练时要在统计报告里按学段核对类别分布，必要时对稀有组合单独补采。

采集来源建议：

1. 公开课/录播视频（B 站、国家中小学智慧教育平台等）用 `collect_helper.py frames` 抽帧；
2. 教室监控（需获得学校许可、去除可识别个人信息）；
3. 课题组自行拍摄的模拟课堂（同学互相扮演学生，7 人可以互为拍摄对象，覆盖不同学段场景）。

## 四、标注规范

### 4.1 框的规则

* **一人一框**，框住整个人（含头部到臀部可视范围），不要只框头部，也不要框到邻座；
* 遮挡严重（只露出头部/局部）时，若可判断行为类别则仍标注，框住可见部分；不可判断则不标；
* 框不能超出图像边界；小到无法辨认行为的目标不标（经验阈值：短边 < 20 像素）；
* 同一学生的不同行为**不要在同一张图里重复标注**，一张图内每个学生只标一个当前行为。

### 4.2 疑难判定优先级

当一个人同时具备多个行为特征时，按以下优先级判定（越靠上优先级越高）：

```
玩手机 > 举手发言 > 站立回答 > 趴桌睡觉 > 书写记笔记 > 阅读看书 > 小组讨论 > 抬头听讲
```

例如：一手举手机、一手举高 → 标「玩手机」；低头手上有笔且在动 → 标「书写记笔记」。

### 4.3 两种数据格式（二选一，推荐 VOC XML）

* **VOC XML**（labelImg 选 PascalVOC 格式）：每张图一个 `.xml`，含 `<size>` 和若干 `<object>`；
* **YOLO txt**（labelImg 选 YOLO 格式）：每行 `class_id cx cy w h`，全部归一化到 0~1。

`scripts/prepare_dataset.py` 两种格式都支持，最终统一转成 YOLO txt 用于训练。

### 4.4 文件命名与目录

```
data/raw/classroom_voc/
├─ Annotations/  000001.xml ...          # 与图片同名
├─ JPEGImages/   000001.jpg ...
└─ 或按场景/学段分目录：
   data/raw/classroom_voc/教室后排_大学/Annotations/*.xml
```

按场景/学段分目录时，`prepare_dataset.py` 会自动统计「场景/学段覆盖」，并写入统计报告。

## 五、质量要求（验收标准）

1. 样本总量 ≥ 5000 张，8 类齐全，每类实例数 ≥ 1200（玩手机 ≥ 1500）；
2. 每个学段、每个场景都有样本（见覆盖矩阵）；
3. 标注校验零错误：`collect_helper.py check` 报出的「类别 id 越界 / 坐标越界 / 框过小」必须清零；
4. 抽检一致性 ≥ 95%：随机抽 200 张由第二位同学复核，错标率超过 5% 需返工；
5. 训练/验证/测试划分互不重叠（脚本自动保证），且稀有类在三份中都出现；
6. 数据集统计报告、标注校验报告、划分清单（`manifest.csv`）齐全，可复现。
