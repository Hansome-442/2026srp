# 路径问题排查

> 这个项目踩过好几次「写死路径」的坑，这篇把它们列清楚，省得你重复踩。
> 最后更新：2026-11-17

---

## 一、解压到哪：五条规则

| 规则 | 说明 |
|---|---|
| **任意盘符都行** | D / E / F 都可以，文档里的 `D:\2026srp` 只是举例 |
| **全英文路径** | `D:\我的项目\2026srp` 这类中文路径，YOLO 读标注时容易出问题 |
| **不要放同步盘** | OneDrive / 坚果云 / 百度网盘同步目录，训练时文件被锁会报错 |
| **别太深** | 数据集有 46,760 个文件，路径太长会撞 Windows 260 字符限制 |
| **留 15 GB** | 环境 7.6 GB（torch 占 5.4 GB）+ 数据 5.3 GB |

**推荐**：`D:\2026srp`、`E:\srp`、`C:\proj\2026srp` —— 短、英文、不在同步目录。

**反例**：

```
C:\Users\张三\OneDrive\桌面\大三下\人工智能课程设计\2026srp     ← 四个雷全踩
```

## 二、路径改动说明（2026-11-17）

早期版本的配置文件里写过**作者机器的绝对路径**，比如：

```yaml
# 旧版 data/dataset.yaml
path: E:\2026srp\data\processed
```

只要你不把项目放 `E:` 盘，训练就会报：

```
FileNotFoundError: E:\2026srp\data\processed\images\train
```

**现在已全部改成相对路径**：

```yaml
path: data/processed        # 相对于项目根目录
```

并且 `train.py` / `val.py` 启动时会自动切到项目根目录，所以从任何地方执行都能找到数据。

> **如果你拿到的是旧包**（2026-11-17 21:00 之前），会有这个问题。
> 判断方法：打开 `data/dataset.yaml`，第一行如果是 `path: E:\...` 就是旧包，重新下载即可。

## 三、五个典型报错

### ① `FileNotFoundError: E:\2026srp\data\processed\images\train`

**原因**：旧包 + 没解压到 E 盘
**解决**：换新包；或把 `data/dataset.yaml` 第一行改成 `path: data/processed`

### ② `FileNotFoundError: configs/classes.yaml`

**原因**：当前工作目录不是项目根目录
**解决**：

```bash
cd /d D:\2026srp          # 先切到项目根
python app\desktop_app.py
```

PyCharm 里则是 **Working directory 没填项目根** → 见 `docs/09`。

### ③ `ModuleNotFoundError: No module named 'torch'`

**原因**：用的是系统 Python 或 conda base，不是 `classroom` 环境
**解决**：`conda activate classroom` 后再运行；或按 `docs/09` 改 PyCharm 解释器

### ④ `FileNotFoundError: runs/best.pt`

**原因**：权重没解压出来，或者工作目录不对
**解决**：确认 `D:\2026srp\runs\best.pt` 存在（18 MB）；不存在就从交接包里重新解压

### ⑤ 训练时 `No labels found` / 数据集为空

**原因**：数据解压层级错了，多套了一层
**解决**：

```
✅ D:\2026srp\data\processed\images\train
❌ D:\2026srp\data\processed\processed\images\train
```

## 四、30 秒自检路径对不对

在项目根目录打开 Anaconda Prompt：

```bash
cd /d D:\2026srp
python -c "import os; print('当前目录:', os.getcwd())"
python scripts/check_env.py
```

`check_env.py` 会打印每个关键路径是否存在：

```
✅ data/processed/images/train        34603 个文件
✅ runs/best.pt                       存在
```

哪一项是 ❌ 或 ⚠️，就照它后面的提示处理。

## 五、记住一句话

**这个项目所有的路径都是相对的。**
只要你在**项目根目录**下执行命令，就不会有路径问题。
换个盘、换个文件夹、换台电脑，都不用改任何配置。
