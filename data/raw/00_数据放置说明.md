## 二、往哪里放（按下面两个目录放，脚本会自动识别）

```
data/raw/
├─ classroom_voc/              ← 【7 类既有数据放这里】VOC 格式
│  ├─ Annotations/             ← 每张图一个 .xml（与图片同名）
│  └─ JPEGImages/              ← .jpg / .png
│
├─ self_collected_玩手机/       ← 【第 8 类自采数据放这里】YOLO 格式
│  ├─ images/                  ← .jpg
│  └─ labels/                  ← 同名 .txt（每行：0 cx cy w h）
│
├─ classes.txt                 ← 8 个中文类别名（labelImg 的预定义类别）
├─ 01_标注分工_7人.md           ← 分工方案（先看这个）
├─ 02_八类定义与标注规范.md      ← 标注判定规则（标注前必读）
└─ 分工表_7人.csv               ← 进度追踪表
```

### 如果你手上是 YOLO 格式的 7 类数据（images/ + labels/ + classes.txt）

不用转格式，直接放成：

```
data/raw/classroom_voc/
├─ images/     ← 原本的 images
└─ labels/     ← 原本的 labels
```

脚本的 `--voc-dir` 参数同时支持 `Annotations+JPEGImages` 和 `images+labels` 两种布局。

### 如果数据是按场景/学段分文件夹的

```
data/raw/classroom_voc/
├─ 教室后排_大学/Annotations/*.xml
├─ 教室后排_大学/JPEGImages/*.jpg
├─ 小组讨论_初中/Annotations/*.xml
└─ ...
```

脚本会递归扫描，并把子目录名统计进「场景/学段覆盖」报告。

## 三、放好之后，双击或运行一条命令

```powershell
# 双击 run_prepare_classroom.bat，或在命令行执行：
E:\anaconda3\envs\pytorch\python.exe scripts\prepare_dataset.py `
  --voc-dir data\raw\classroom_voc `
  --yolo-dir data\raw\self_collected_玩手机 `
  --oversample-min 300
```

会生成：

* `data/processed/images|labels/{train,val,test}` —— 训练用的标准数据集（分层划分，稀有类三份都有）
* `data/dataset.yaml` —— 训练配置（8 类）
* `reports/dataset_stats.md` —— 中文统计报告（样本量、每类实例数、未识别标签、场景覆盖）

看到报告里「未识别标签」一节不为空，说明标注里出现了别名表没覆盖的写法，
把它补进 `configs/classes.yaml` 的 `aliases` 再跑一次即可。

## 四、放数据前请自查

- [ ] 图片和标注**同名**（`000123.jpg` ↔ `000123.xml` 或 `000123.txt`）
- [ ] 类别名用中文全称：抬头听讲 / 阅读看书 / 书写记笔记 / 举手发言 / 站立回答 / 小组讨论 / 趴桌睡觉 / 玩手机
- [ ] 没有 0 字节的标注文件、没有超过图片边界的框
- [ ] 图片能正常打开（不是 HEIC 或其他异常格式；必要时先批量转 jpg）
- [ ] 至少覆盖 4 个学段、4 类场景（见 `02_八类定义与标注规范.md`）

自查也可以用脚本：

```powershell
E:\anaconda3\envs\pytorch\python.exe scripts\collect_helper.py check --labels data\raw\classroom_voc\Annotations
```
（YOLO 格式则把 `--labels` 指向 `data\raw\classroom_voc\labels`）
